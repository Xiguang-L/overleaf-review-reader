# Overleaf Review Reader privacy policy

Overleaf Review Reader is an independent Chrome extension. It reads review comments from the Overleaf project you have open so that you can view, search and export them.

**Data used.** After you open the extension from a project tab and allow read-only access, it uses the project URL and ID to request that project's review data from Overleaf over HTTPS. It reads comment and reply text, thread and message IDs, author display names, timestamps and resolution status. If you select **Include selected source text**, it also requests available source excerpts and positions. The browser uses your existing Overleaf session for these requests. The extension does not read, copy, store or export login credentials or cookies.

**Storage and sharing.** The extension keeps the review data in memory for the open reader tab. It has no server, analytics or advertising, and it does not send review data to the publisher or to third parties. It saves your language choice and read-access confirmation in Chrome's local extension storage. A JSON file is written only when you choose to export, and it stays where your browser saves it unless you move or share it yourself. The file can contain unpublished text and collaborator names.

**Control.** Close the reader tab to discard the in-memory snapshot. Remove the extension to clear its saved preferences and confirmation. Delete any downloaded export separately if you no longer need it. The extension cannot post, resolve or delete comments or make changes to your Overleaf project.

The extension's use of user data adheres to the Chrome Web Store User Data Policy, including the Limited Use requirements. For questions about the extension, use the support contact on its Chrome Web Store listing.

# Overleaf Review Reader 隐私政策

Overleaf Review Reader 是独立的 Chrome 扩展，用于阅读、搜索和导出当前打开的 Overleaf 项目的 Review 评论。

**使用的数据。** 你从项目标签页打开扩展并允许只读访问后，扩展会用项目地址和 ID 通过 HTTPS 向 Overleaf 请求此项目的评论数据，包括评论和回复正文、讨论和消息 ID、作者显示名、时间戳及解决状态。勾选「同时读取被圈选的原文」时，还会请求可用的原文片段和位置。浏览器使用当前的 Overleaf 登录会话，扩展不读取、复制、保存或导出登录凭据或 Cookie。

**存储和共享。** 评论保存在扩展阅读页的内存中。扩展没有后端、分析统计或广告，不向发布者或第三方传送评论数据。扩展在 Chrome 本地保存界面语言和只读访问确认。只有你主动点导出才会生成 JSON；在你自行移动或共享前，文件留在浏览器保存的位置。导出的文件可能包含未公开的内容和合作者姓名。

**删除数据。** 关闭阅读页可清除内存里的评论快照；卸载扩展可清除语言偏好和只读访问确认。下载的 JSON 需要单独删除。扩展不会发布、解决或删除评论，也不会修改 Overleaf 项目。

扩展对用户数据的使用遵循 Chrome 网上应用店的用户数据政策，包括用途限制要求。如有问题，请使用扩展商店页面上的支持联系方式。
